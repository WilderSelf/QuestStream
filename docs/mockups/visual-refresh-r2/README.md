# Visual refresh — round 2: Gallery × Grimoire (Aug 2026)

Direction chosen from round 1: **The Gallery as the base** (sidebar navigation,
medium-large aurora-gradient scene cards, persistent now-playing rail) with
**book theming from the Grimoire as visual garnish** — ribbons, sigil-ring pads,
wax-seal duck, ornament rules. Labels stay plain (Scenes, Soundboard, Up next);
type is Fraunces for display over Outfit for UI.

Five variations of the home screen, each placing the garnish somewhere
different so the right dose is easy to pick. Elements are composable — any
mix of these can be assembled into the final design.

| # | Variant | Where the garnish lives |
|---|---------|-------------------------|
| h1 | **Quiet Ribbon** | Minimal: ribbon bookmarks on scene cards (color per scene, amber = on air) + Fraunces display. Everything else stays Gallery-modern. |
| h2 | **The Margin** | The right rail becomes the book's margin: sigil-ring soundboard with labels, wax-seal duck with its rule of thumb, ornament-tailed section headers. Cards as in h1. |
| h3 | **Bookplate** | The cards carry it: aurora art framed like a pasted-in plate (double hairline inset), centered Fraunces titles with a small fleuron, ribbons kept. Rail stays modern. |
| h4 | **Illuminated** | The structure carries it: centered chapter-style header with an ❦ ornament rule, double-rule shelf dividers, a page frame around the content, ribbon-marker active nav. Cards plain + ribbons. |
| h5 | **Gilt** | All of it, tuned down: ribbons + light plate inset on cards + sigil rail with seal + illuminated header + page frame + ribbon nav. The maximal blend that still reads as an app. |

Generated by `gen-hybrids.mjs` variant flags in the working session; the
committed HTML files are static and self-contained apart from Google Fonts.
