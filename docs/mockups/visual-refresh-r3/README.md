# Visual refresh — round 3: Grimoire flanks, Gallery center (Aug 2026)

Per feedback on round 2: the Grimoire mockup's left and right rails carried the
flourishes worth keeping, and the Gallery's central layout carried the browsing.
So round 3 lifts the Grimoire's flanks nearly verbatim and wraps them around the
Gallery center:

- **Left rail** — Chapters · Scenes as bookmark-notched cards (amber ribbon +
  tint = on air, F-keys), Appendices · Playlists, the italic drag hint.
- **Right rail** — the margin: sigil-ring soundboard, footnote-numbered Up next,
  Sounding-now level bars with a short colophon note, wax-seal DUCK anchored at
  the bottom.
- **Top/bottom** — the tome header (italic campaign title, Discord pill) and the
  Grimoire transport bar.
- **Center** — Gallery: search + paste-link + import, serif greeting, then shelves.

Two variants, differing only in the center (scenes appear in the left rail either
way — the rail is the quick switcher):

| File | Center |
|------|--------|
| `g1-chapters-cards` | Scenes shelf with the aurora art cards (3 large + View all), Recently added, Ambience loop cards. Scenes are browseable art AND a rail switcher. |
| `g2-reading-room` | No scenes shelf — Recently added (full), Ambience loop cards, Library groups by setting. Scenes live only in the rail. |

Type: Fraunces display, Spectral italics for margin notes, Outfit UI,
JetBrains Mono data. Nord tokens as in rounds 1–2.
